# Minidegree Digital Humanities

**Digital Methods for Humanities Research**

An educational program at **HSE University (Higher School of Economics), Faculty of Humanities**.

Minidegree Digital Humanities introduces students to computational approaches to humanities research, combining theoretical foundations with practical skills in data collection, natural language processing, machine learning, and digital methods.

The program explores how computational tools can help us study texts, languages, cultural phenomena, historical sources, images, and social connections.

Our courses combine interdisciplinary thinking, hands-on experimentation, and project-based learning.

---

## Courses & Learning Materials

The program consists of four interconnected courses. Each course has a dedicated GitHub repository containing lectures, practical assignments, Jupyter notebooks, code examples, and other learning materials.

### 01. Introduction to Digital Humanities

An introduction to Digital Humanities research, computational methods, and digital approaches to the study of humanities data.

**Topics:**
- Foundations of Digital Humanities research
- Regular expressions and text preprocessing
- Tokenization and lemmatization
- Quantitative text analysis
- Culturomics and distant reading
- Stylometry and authorship analysis
- Geospatial analysis
- Topic modeling
- Social network analysis
- Optical Character Recognition (OCR) and Computer Vision (CV)
- Semantic vector representations

**Repository:** [miniDH-intro](https://github.com/minidegree-dh/minidh-intro)

### 02. Data Collection for Humanities Research

A practical introduction to automated data collection from the web, working with APIs, and building reproducible data collection workflows.

**Topics:**
- Web scraping fundamentals: HTTP, HTML, and CSS selectors
- Static website scraping with Requests and BeautifulSoup
- Structured data formats: JSON, XML, and CSV
- REST APIs, authentication, and pagination
- Dynamic website scraping with Selenium
- Data preprocessing with Pandas
- Git, version control, and repository documentation
- Ethics and legal aspects of data collection

**Repository:** [miniDH-scraping](https://github.com/minidegree-dh/miniDH-scraping)

### 03. Natural Language Processing & Computer Vision

An introduction to computational linguistics, natural language processing, and methods for working with textual and visual data.

**Topics:**
- Linguistic text processing
- Syntactic parsing and Named Entity Recognition (NER)
- Text representations: TF-IDF, Word2Vec, and FastText
- Contextual embeddings
- Topic modeling: LDA and BERTopic
- Text classification and sentiment analysis
- Semantic search
- Transformer architectures and language models
- Using and fine-tuning models with Hugging Face

**Repository:** [miniDH-NLP-CV](https://github.com/minidegree-dh/miniDH-NLP-CV)

### 04. Machine Learning for Text & Image Processing

An introduction to machine learning algorithms and neural network approaches for analyzing textual and visual data.

**Topics:**
- Machine learning fundamentals
- Text representation and feature extraction
- Text classification and prediction
- Working with pretrained neural network models
- Image processing and feature extraction
- Image classification
- Introduction to Computer Vision
- Multimodal models: CLIP
- Cross-modal search and text-image matching

**Repository:** [miniDH-ML](https://github.com/minidegree-dh/miniDH-ML)

## Student Research Showcase

**From learning digital methods to conducting independent research.**

The program emphasizes practical application of computational methods to humanities research.

Students work with real-world datasets, explore digital tools, develop research workflows, and complete independent projects addressing questions in the humanities.

The **Student Research Showcase** is a collection of research and practical projects developed by students of Minidegree Digital Humanities at HSE University.

Projects demonstrate how digital methods can be applied to explore cultural, historical, linguistic, and social phenomena.

**Research areas include:**
- Computational Text Analysis
- Natural Language Processing
- Digital Cultural Studies
- Stylometry and Culturomics
- Network Analysis
- Geospatial Humanities
- Machine Learning
- Computer Vision
- Web Data Collection and Digital Archives

**Explore student projects:**

[Minidegree Digital Humanities — Student Projects](https://github.com/minidegree-dh/minidh-student-projects)

We aim to build an open collection of student research, encourage reproducible research practices, and promote interdisciplinary collaboration.

## Our Approach

We believe that digital technologies offer new ways to ask questions about culture, society, language, and history.

Digital Humanities is not simply about applying technology to the humanities. It is about developing new research perspectives through interdisciplinary thinking, computational experimentation, and critical reflection.

**Learn. Explore. Analyze. Visualize.**
